# Veiled Pages — previous website address

This repository preserves previously shared feedback and privacy links. Its build publishes redirects from `/`, `/feedback/`, and `/privacy/` to the corresponding routes at https://yarynamashta.github.io/veiled-pages-site/.

The active website is maintained at https://github.com/yarynamashta/veiled-pages-site. Edit content there. Historical source files here are not published by this build.

Run `npm run build` to create the redirects. GitHub Actions publishes `dist/`. The redirects preserve only supported platform/version context and discard other query parameters. A standard refresh and visible link also work without JavaScript.
